# Documentation

Esta carpeta reúne la documentación técnica asociada con la arquitectura IoT desarrollada durante la investigación .

La documentación complementa el código fuente, los datos experimentales y los procedimientos de calibración disponibles en este repositorio, proporcionando la información necesaria para comprender, instalar, configurar y reproducir el sistema propuesto.

## Contenido

- Arquitectura del sistema
- Manual de configuración-reconocimiento XBEE
- Manual de configuración red, dirección, transmisión y recepción de XBEE
- Manual_aws_ de Conexión cliente- bróker MQTT 


## Objetivo

Proporcionar una guía técnica que facilite la implementación y reproducción de la arquitectura IoT para el monitoreo de humedad del suelo en el cultivo de palma datilera desarrollada en esta investigación.
